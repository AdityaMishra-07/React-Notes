Day-12 useEffect Hook -3 [ unmounting phase]

Countdown timer

useEffect
Hook Lifecycle Notes:

1. Mount Phase (component first appears)

What happens?

React runs the
useEffect
callback after the DOM is painted.
React does not call any cleanup function (because there's nothing to clean up yet).

Why?

This is the first time the component is mounted.
The
useEffect
Logic includes subscriptions, event listeners, timers, etc.

Example:

// Run every time useEffect(() => { console.log("Mounted"); // runs once return () => { console.log("Cleanup"); // not called at mount }; }); // run only 1 time useEffect(() => { console.log("Mounted"); // runs once return () => { console.log("Cleanup"); // not called at mount }; }, []);
​

2. Update Phase (dependencies change — only if deps are provided)

When?

Happens only if the dependency array (
[dep1, dep2]
) changes.
React:
Calls the cleanup function from the previous effect.
Then runs the new effect.

Why?

Prevents stale data or duplicated listeners.
Ensures the effect reflects the latest state/props.

Example:

useEffect(() => { console.log("Effect ran"); return () => { console.log("Cleanup before next effect"); }; }, [count]);
​

3. Unmount Phase (component removed from DOM)

What happens?

React calls the cleanup function returned by
useEffect
.
This happens only once when the component is removed.

Why?

To stop background work: timers, event listeners, subscriptions.
Prevents memory leaks and crashes.

Example

useEffect(() => { const id = setInterval(() => console.log("tick"), 1000); return () => { clearInterval(id); console.log("Component unmounted, timer cleared"); }; }, []);

It offers a way to create "global" variables accessible by any component within an application, regardless of its nesting level. Tailwind CSS is a utility-first CSS framework for rapidly building modern user interfaces. Instead of writing custom CSS, you apply pre-defined classes directly in your HTML/JSX.

Method 1: Installing Tailwind CSS as a Vite plugin

1. Create your project

npm create vite@latest my-project cd my-project
​

2. Install Tailwind CSS

npm install tailwindcss @tailwindcss/vite
​

3. Configure the Vite plugin

Edit the
vite.config.js
:
import { defineConfig } from 'vite' import tailwindcss from '@tailwindcss/vite' export default defineConfig({ plugins: [ react(), tailwindcss(), ], })
​

4. Import Tailwind CSS

Edit
src/index.css
(or create if missing):
@import "tailwindcss";
​

5. Start your build process

npm run dev
​
